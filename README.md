# Simple Calculator

A simple calculator built using **C++ and Qt Creator**.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Simple and user-friendly interface

## Technologies Used

* C++
* Qt Framework
* Qt Creator
* CMake

## How to Run

1. Clone this repository.
2. Open the project in **Qt Creator**.
3. Open `CMakeLists.txt`.
4. Configure the Qt kit/compiler.
5. Build and run the project.
